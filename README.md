# Chatalog

A learning memory companion for AI chats. Chatalog turns your Claude and ChatGPT learning
conversations into a verified, searchable knowledge base, where every note links back to the
exact message it came from and is checked against it.

**Capture → Verify → Organize → Find → Review → Brief**

Runs locally. Your chat data never leaves your machine.
